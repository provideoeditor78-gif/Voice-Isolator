VOICE ISOLATOR
===============

INSTALL
Windows : INSTALL_WINDOWS.bat par double-click karein.
Mac     : INSTALL_MAC.command par double-click karein (na khule to right-click > Open).

PEHLI DAFA
Panel pehle license key mangega (jo khareedne ke baad mili). Key daal kar Activate dabayein.
After Effects / Premiere kholein > Window > Extensions > Voice Isolator
"Download essential files" dabayein. Panel aap ke computer ke hisaab se
sahi files khud download karke setup kar dega. Ye sirf ek dafa hota hai.
Uske baad internet ki zaroorat nahi.

REMOVE
Windows: UNINSTALL_WINDOWS.bat
